# Lunora PK — Premium Home Essentials & Self-Care E-Commerce

**Lunora PK** is a modern, high-performance e-commerce platform designed to offer a seamless online shopping experience for premium home textiles, bedsheets, comforters, and natural self-care products in Pakistan. Built with a custom Next.js frontend, a robust Express.js backend, and a scalable MongoDB database, it combines aesthetic UI design with practical, localized e-commerce features.

## ✨ Key Features

### 🛋️ Refined Storefront & Shopping Experience
* **Minimalist Aesthetic:** Dark/light responsive UI with sleek typography, high-contrast visual hierarchy, and smooth product showcases.
* **Seamless Navigation:** Intuitive product catalog browsing for bedsheets, comforters, handmade soaps, and natural hair oils.
* **Custom Cart & Checkout:** Frictionless shopping cart workflow optimized for high conversion and fast user interactions.
* **Localized Logistics:** Built-in Cash on Delivery (COD) workflow and direct WhatsApp support integration for swift customer assistance across Pakistan.

### 💼 Powerful Admin Management System
* **Catalog & Inventory Control:** Real-time CRUD capabilities to manage product stock, update pricing, upload product variations, and adjust categories.
* **Order Processing Engine:** Centralized dashboard to track incoming customer orders, manage order statuses, and monitor fulfillment pipelines.

---

## 🛠️ Tech Stack

### Frontend & UI
* **Next.js & React.js** — Server-side rendering (SSR) and static generation (SSG) for ultra-fast page speeds, SEO optimization, and smooth navigation.
* **Tailwind CSS** — Custom utility-first styling delivering precise layouts, clean whitespace, and modern micro-interactions.

### Backend & Database
* **Node.js & Express.js** — Scalable API architecture managing secure data endpoints, authentication, and core business logic.
* **MongoDB & Mongoose** — Flexible NoSQL database model for quick product queries, cart state persistence, and dynamic order handling.
